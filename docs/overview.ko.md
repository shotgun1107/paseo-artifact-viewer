# Paseo 아티팩트 뷰어

대화에서 만든 HTML 페이지, SVG 그림, React 컴포넌트를 열 수 있습니다. 대화 카드를 누르면 선택한 버전이 대화 오른쪽에 열립니다. 왼쪽 아티팩트 보관함에서는 같은 데몬의 다른 대화에서 만든 결과를 찾고 메인 영역 전체에서 볼 수 있습니다.

## 어떻게 동작하나요

플러그인은 새로 만드는 모든 에이전트의 저장된 시스템 지침에 아티팩트 사용 안내를 덧붙입니다. 플러그인을 제거한 뒤에도 기존 에이전트에 추가된 지침은 남습니다. 이전 대화에서는 `/artifact-guide`로 현재 에이전트에게 안내를 전달할 수 있습니다. Codex와 Claude 대화에는 발행·읽기·목록 조회·열기 도구 네 개를 추가합니다. 다른 공급자의 응답에서는 지원하는 코드 블록을 추출합니다.

턴이 끝날 때와 대화를 열어 아티팩트를 불러올 때, 추출기는 최근 대화 항목을 최대 1,000개 읽습니다. 완성된 코드 블록과 같은 턴의 답변에서 링크한 파일 중 완료된 작성·수정 기록으로 내용을 확인할 수 있는 파일을 저장합니다. 링크를 따라 디스크의 파일을 읽지는 않습니다. 1,000개보다 오래된 항목은 추출 범위에서 제외됩니다. 이미 저장된 카드가 대화에서 사라졌을 때는 해당 카드 ID를 찾기 위해 더 오래된 기록도 조회할 수 있습니다.

## 무엇이 필요한가요

데스크톱 또는 웹 Paseo와 호환되는 데몬이 필요합니다. 이 버전은 Paseo 0.16.1 이상 0.18 미만을 대상으로 하며 데몬의 Node 런타임이 `node:sqlite`를 지원해야 합니다. 데몬에서 신뢰한 플러그인 사용을 활성화하세요. 별도 브라우저 탭에서 버전을 열 때는 브라우저와 데몬이 같은 컴퓨터에 있어야 합니다.

## 어떤 데이터를 저장하고 보내나요

데몬은 본문·버전 이력·카드 전달 기록을 로컬 SQLite에 저장합니다. 보관함은 해당 데몬의 모든 대화 결과를 보여 줍니다. 제목 검색, 고정, 이름 변경, 복제, 파일 내보내기, 이전 버전 복원을 지원합니다. 삭제는 항목을 숨기는 작업이며 본문은 DB에 남습니다. 플러그인을 제거해도 `$PASEO_HOME/plugin-data/paseo-artifact-viewer/` 아래의 DB 파일은 남습니다.

모델이 만든 HTML과 React 코드는 격리된 프레임에서 실행됩니다. HTML과 SVG는 외부 자원을 차단한 상태로 시작합니다. 외부 HTTPS 주소를 참조하는 문서는 먼저 본문과 기본 도형을 정적으로 표시합니다. 사용자가 허용하면 본문에 지정된 HTTPS 주소에서 스크립트·스타일·이미지·글꼴을 불러올 수 있고, 그 서버에 자원 요청이 전달됩니다. HTML을 별도 브라우저 탭에서 열어도 먼저 오프라인 상태로 표시합니다.

앱 안의 React 미리보기는 사용자 동의 후 컴포넌트 본문을 CodeSandbox 번들러로 전송합니다. React를 별도 브라우저 탭에서 열면 기한이 있는 로컬 주소를 사용합니다. 사용자가 동의하면 브라우저가 esm.sh에서 지원 라이브러리를 받아 컴포넌트를 실행합니다. 내보내기는 선택한 버전을 파일로 저장합니다.

## 어떤 제한이 있나요

미리보기는 최대 512,000자의 단일 파일을 지원합니다. 휴대폰 앱에서는 미리보기와 보관함을 사용할 수 없습니다. 대화 카드 전달이 반복해서 실패하면 재시도가 멈출 수 있습니다. 전달 실패는 플러그인 로그에 남고 진단용 RPC로 조회할 수 있습니다. 화면에는 실패 목록을 표시하지 않습니다. 이때도 저장된 아티팩트는 읽을 수 있습니다. 데몬이나 플러그인의 버전을 변경하기 전에 SQLite DB를 백업하세요.
